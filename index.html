      Other MCP clients

      Files agents make are saved to . Every agent action, and every refused request, is written to . Anyone with the token can control recording, so keep it private; press New token if it leaks. Copied commands contain the token, and the agent's config file will store it.

      What agents can do

      Record

      • list_sources · start_recording
      • pause_recording · resume_recording
      • stop_recording · recording_status

      Review

      • list_files · media_info
      • extract_frame (the agent sees the frame)
      • open_in_editor

      Produce

      • trim_video · join_videos
      • generate_voiceover · add_audio
      • add_captions · convert_video

      Try asking your agent: “Use FrameBase to make a two-minute narrated review of the Notes app.” Clients that support MCP prompts also get a product_review prompt.
